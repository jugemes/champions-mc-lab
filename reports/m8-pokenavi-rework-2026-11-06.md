## 全敗条件の反証

[Claude監査](https://github.com/jugemes/champions-mc-lab/pull/113) で全敗だった4条件を、Claudeと異なるシードで再現した。旧6体の選出と行動だけを変更した案と、入れ替え案を比較した。下表は旧案／選出・行動だけ変更／入れ替え案。

| 相手の条件 | 12戦 | 別シード16戦（旧／入れ替え） |
|---|---:|---:|
| ペリッパー → ブリジュラス | 0／12／12 | 0／14 |
| ペリッパー → ラグラージ → ブリジュラス | 0／5／5 | 0／9 |
| ギャラドス → メガガブリアスZ → ミミッキュ | 0／0／12 | 0／16 |
| スカーフガブリアス先発＋特殊メガカイリュー後発 | 0／11／10 | 0／12 |
| 追加条件のペリッパー → 素早さ32のひかえめブリジュラス | 0／11／11 | 0／16 |
| 追加条件のスカーフガブリアス初手いわなだれ | 4／6／8 | 5／9 |

12戦系列は81条件で各案972戦。旧案792勝、選出・行動変更案816勝、入れ替え案860勝。全敗はそれぞれ5、1、0条件。別シードは重点8公開6ケース45条件×16試行で各案720戦。旧案517勝（5条件全敗）、入れ替え案619勝（全敗なし）。全比較4,356戦、選択エラー0。対人勝率は未測定。

- **雨**の対ブリジュラスは、ポケナビの候補にあったグソクムシャのインファイトやメガルカリオZも比較した。最終候補では既存のサーフゴー先発を維持し、ペリッパーにシャドーボールを選んでブリジュラスへの即交代にも打点を残す。ラグラージを経由した連続交代は5/12、9/16で、選出上の弱点が残る。 [ポケナビのブリジュラス対策](https://pokenavi.jp/counters/archaludon/)
- **ギャラドス**の2回目の交代は、Claudeの台本ではアシレーヌ着地が条件だった。比較中にヌメルゴン案では2回目が起きないことを検出したため、その初期結果は判定から除いた。確定比較ではアシレーヌ・ヌメルゴンのどちらが出てもミミッキュへ交代させ、上記2系列で旧案・入れ替え案の各28試行すべてで実際に交代したことをログで確認した。ヌメルゴンはガブリアスZのだいちのちからをふうせんで無効にし、ミミッキュにはラスターカノンを使える。
- **混合**はマスカーニャ先発をやめ、グソクムシャ先発。ガブリアス対面でヌメルゴンに引き、れいとうビームで圧力をかける。カイリュー先発に対しては初手メガ＋ふいうちを選ぶ。メガメタグロス先発の通常条件は8/12・11/16で、旧12/12・16/16から悪化した。
- **ミミッキュの形態名**はギャラドス系統の条件に限定して両形態を扱う。全ケースに一律適用したClaudeの事後診断は採用していない。晴れのX/Yは公開6が同じなら選出を統一し、ヌメルゴンで地面技を透かす。ふうせん持ちサーフゴーには、じしんを選ぶ前に交代または打点で対応する。

## 残る弱点と再現

雨の連続交代は上記のとおり。ゲンガー先発の複数メガ候補は4/12・10/16、鋼3体は5/12・10/16、砂のニンフィア先発は5/12・8/16。次の採否判断ではこれらを優先する。Claude監査は旧6体へのもの。改修案の採用・育成は保留。

固定 `SHOWDOWN_DIR` で `M8_REWORK_TRIALS=12 M8_REWORK_BASE=67190000 node m8-pokenavi-rework-20261106.js`。重点再試験は `M8_REWORK_TRIALS=16 M8_REWORK_BASE=67230000 M8_REWORK_VARIANTS=original,goodra M8_REWORK_CASES=mixed,rain,gyarados,sun,charX,sand,multiMega,steelBunker node m8-pokenavi-rework-20261106.js`。生ログは `output/m8-pokenavi-rework-<seedBase>.json`。固定選出と交代条件のユニットテストは2件。通常CIとローカルBattleの結果は区別する。
