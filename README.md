# Pokémon Champions M-C Lab

ポケモンチャンピオンズ（シングル・レギュレーションM-C）の構築検証プロジェクト。

検証エンジンは[Pokémon Showdown](https://github.com/smogon/pokemon-showdown)を利用し、GitHub Actionsで再現可能な試験を行います。

対戦AIの精度が確認できるまでは、試験結果を実際のランク戦勝率とはみなしません。
