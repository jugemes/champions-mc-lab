## 具体的な発見

PR #28のログ（07_M7_baxcalibur_offense, rational-opponent, seed `[21186,29606,35976,35176]` と `[57625,46147,8147,6499]`）では、**セグレイブがミトムへ無効の地震を12ターンほど連打**し、こちらの**ミトムもねつこうかんで無効と公開されたおにびを12ターンほど連打**。双方ともターンAI `v3`。これはShowdownに仕様が無いのではなく、BotがShowdown公開情報と戦術へ結び付けていなかった問題。

PR #29は`v3-public-immunity` opt-inを追加し、**公開の無効化イベントのみ**から同一相手への無効技を再選択しない候補実装。4つの合成条件で旧/旧0勝、新自分/旧敵2勝、新自分/新敵1勝（**ランク戦勝率ではない**）。相手のプレミで勝つ不健全さを検出できた一方、改修AIが人間相手に強い証明ではない。

## Claudeの独立担当

1. **仕様と公開情報境界の厳格なレビュー**。PR #29の実装／テストが、本当は無効でない技まで誤って学習しないか、対象相手・ログ順序・相手交代・再戦入替・特性/フォルム変化・技対象・天候/フィールド・命中失敗・全体技・交代時の既知情報・双方の独立性の観点で監査。重大不備を見つけたら失敗する回帰テストを先に用意。真の敵Battleや未公開3体/技/持ち物の参照は厳禁。
2. **双方が合理的に行動する状況での独立比較**。相手が`Earthquake`無効後に`Glaive Rush`や交代を選ぶ勝ち筋を評価し、こちらも`Will-O-Wisp`無効後の`Hydro Pump`、`Thunderbolt`、交代先を公開情報だけで比較。現行AIのスコア根拠を確認し、無効学習だけで足りないなら原因と最小改修案を示す。こちらのみ改善した対戦勝数は採用根拠にしない。
3. **0/12など苦手反例の対人向け勝ち筋**。公開相手6から合理的な双方3体＋初手を評価し、メガグソクムシャ＋ガブ＋ミミッキュ、グソクムシャ＋セグレイブ、リザY等の本当に解けない負け筋を切り分ける。具体的な実戦選出・初手・注意する相手の分岐を提案。現行6体/育成型は勝手に変えない。
4. **試験精度と過適合の防止**。新旧のBot、相手だけ改善、双方改善を同seedで比較し、別seed、別公開6、別相手3仮説も確認。相手の不合理行動で発生した勝利を性能改善に数えない。未完成の強制交代・ボルトチェンジ分岐を勝ち筋として扱わない。
5. **出力と実装**。独立ブランチ `claude/*` →独立PR（必要ならPR #29 headをbaseに積む）→ GitHub Actions CI。対戦性能が未改善なら未改善と報告。改修後の判断が実際に何を変えたか、全て公開情報で説明する。無関係な大規模書換えを避ける。
