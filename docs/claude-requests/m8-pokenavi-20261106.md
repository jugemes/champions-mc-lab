## 依頼

1. 6体の合法性を公式M-C参加可能一覧と固定Showdown `3a766f2cfb5e51c1e428cfe87d0dba91a8f01640` の `gen9championsbssregmc` で点検。メガは1戦1体、能力Pは合計66・各32以下。ポケナビの種族別集約と、候補の実装型による実Battleの結論を分ける。
2. 既知の弱点は特殊メガカイリュー先発3/10、ギャラドスからメガガブリアスZへ即交代4/10、鋼3体とゲンガー先発4/10。相手が有利なメガを実際に出し、合理的に交代したかログで調べる。雨のペリッパー→メガラグラージ→ブリジュラス、同じ公開6に対するリザードンX/Y、イエッサン＋サイコシードのオオニューラも点検。特に雨でサーフゴーを場に残してタスキを守る手順が、相手の連続交代やブリジュラス後発に耐えるかを確認する。
3. 公開6段階でこちらの3体と初手を固定する。相手の実選出・道具・技は公開される前に使わない。既存680戦／案はシミュレーションなので、都合のよい行動や調整済みの枝への適合を疑う。新しい反例は試験前に両者の選出・初手・分岐・シードを記録し、利用枠内で小規模に再現。コードの読み取りと負け筋の検証を優先し、根拠の薄い大規模な再探索は行わない。
4. 採用判断は「試用可」「要修正」「見送り」と理由を示す。相手の公開6・実選出・型、こちらの3体、初手からの負け筋、再現コマンド、試行数、未検証を記録。成果は監査用ブランチの `reports/m8-pokenavi-claude-audit-2026-11-06.md` またはPR #108への独立レビューとして保存し、出力のリンクをPR #108に残す。修正を提案するときは監査用ブランチの差分とし、採否はユーザー判断に委ねる。
