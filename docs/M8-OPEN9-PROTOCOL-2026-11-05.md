# OPEN9：OPEN8の結果からの構造変更仮説（結果前固定）

## 仮説
O2のサーフゴーを、既存実戦型のヨプすなおこしバンギラスへ置換したO8を新たな提案6体として試す。晴れ再展開に対する天候の上書き余地、悪/岩打点、Ghost耐性を得る仮説。明確な代償は鋼/ゴースト特殊打点・ふうせん地面無効・おうごんのからだ喪失、格闘/地面/草/水への弱さ、砂で襷セグレイブ/ロトム/ゴリラ/ラウドが削れること。砂でグラス回復を無料とみなさない。現行6体を土台として固定する意味ではない。

## 条件と止める基準
O2_controlとO8_sand_bridgeを同じ15公開6/33枝、60選出・学習1seed左右・別検証2seed左右で比較。OPEN8と違うseedOffset600000、計8184 full Battle。候補を結果後に変更しない。既知の公開6/型への適合であり新しい未見型holdoutではない。0/4が残れば完成認定しない。仮に0/4なしでも以下補足反証とClaude独立監査が必要。

補足5公開6/10敵3はOPEN8補足と同一、各4試行（主試験とは異なる旧補足seedを再使用するため開発用）。O8とO2双方、公開6のみを見るchooseThreeで同条件固定。雪壁/トリル/ReflectはT1に展開する機構fixture。こちらの選出探索改善と構築補完を混同しない。既知失敗枝の選出を60通り再探索する場合は別途全枝共通3の条件を固定し、同じ評価結果を見て最善3を拾って完成としない。

公式参加可能全種照合・未知の天候/壁バトン/しっぽきり/複数型の検証・Claude本人の独立成果は未完了。実戦構築変更・main merge・追加課金なし。
