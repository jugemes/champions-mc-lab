このリポジトリはChatGPTと共同で、ポケモンチャンピオンズのM-Cシングルでチャンピオン級を目指す研究です。**私からClaude Codeへの完全引継ぎではありません。** ChatGPTはこれまでどおり構築相談・実戦分析・GitHub上でのレビューを続けます。あなたには独立した厳しい監査とコード改善を依頼します。

最初にルートの `CLAUDE.md`、`docs/HYBRID-COLLAB-2026-10-27.md`、`docs/REAL-BATTLE-CASES-2026-10-27.md`、GitHub Issue #2、それから `docs/HANDOVER-2026-10-14.md` と最新コード・Actions結果を読んでください。古いC/E「勝率上位」という結論は信用せず、現行暫定6体と実戦の反例を優先してください。

1. これまでの対戦AIで、なぜ人間の合理的な相手選出を再現できなかったのか、`preview-policy.js`、`preview-strategic.js`、`lab.js`、`damage.js`、`decision-v2.js`を独立監査してください。**相手の6体を見せたら相手がメガリザードンYを通しに来る**ようなケースで、相手がリザを不自然に切った勝利を構築の強さと誤認しないこと。
2. `docs/REAL-BATTLE-CASES-2026-10-27.md`の人間同士の対戦を回帰検証素材として、特に **イエッサンのマジカルシャイン＋スカーフ候補（持ち物は未確認）**、E案vsメガリザY、C案vs通常オボンギャラ・シャンデラを正しいShowdownのM-Cで扱えるか確認してください。対戦実績にない相手の情報は作らないでください。

4. まずは **監査結果・最小再現テスト・優先度別修正案**だけを提出してください。条件の違うシミュレーションを大量に増やすことや、構築6体を勝手に改変することは避けてください。

6. 専用ブランチ（例：`claude/hybrid-01-audit`）で変更してPRを作成し、**私が確認するまでマージしないでください**。PRには ChatGPTが反証すべき点、残った不確実性、育成の追加費用が出るかどうかを必ず記載してください。

分析の最重要判断基準は「対戦AIの総勝率」ではなく、**相手がこちらの弱点をつく合理的な選出・技選択をしたときでも、3体でどのように勝つかを説明・検証できるか**です。疑義があればChatGPTの過去の説明にも遠慮なく反論してください。
